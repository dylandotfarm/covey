# Contributing

covey does not accept pull requests at the moment.

The code is public so that you can read it, build it, and run it. The MIT licence lets you
fork it and change your own copy. But the project is early and the design still moves week to
week, so a patch from outside can go stale before anyone reads it. A workflow closes pull
requests from people who are not collaborators.

**Bugs and ideas are welcome.** Open an issue. Say what you did, what you expected, and what
happened instead. For a terminal problem, give the terminal and the version — the TUI depends
on the kitty keyboard protocol for some keys.

This file changes when the project is ready for patches.
